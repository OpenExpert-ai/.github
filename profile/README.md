# OpenExpert

Local-first AI operations dashboard: isolated experts, tool-using chat, human-approved actions and a complete audit trail — **all on your machine**. No cloud, no accounts, no database server.

**Open source under the MIT license.**

**[Repository](https://github.com/OpenExpert-ai/OpenExpert)** · **[Quick start](https://github.com/OpenExpert-ai/OpenExpert/blob/main/docs/en/00-quickstart.md)** · **[Website](https://openexpert-ai.github.io/OpenExpert/)**

```sh
docker run --rm -p 127.0.0.1:3000:3000 -v openexpert-data:/data ghcr.io/openexpert-ai/openexpert:latest
```
